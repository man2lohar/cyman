NKDA Smart DCR Pre-Check (unofficial)

Check your DXF drawing against the Smart DCR User Manual v2.0 before you submit. Your file stays on your device: everything runs in your browser.

The marked-up DXF adds circles, grey crosses and error text on a new layer called NONCOMPLIANT. Smart DCR ignores that layer.
Drag to pan · scroll or pinch to zoom · click a red or amber ring to select an issue · grey cross = object with an error
Unofficial tool based on the NKDA Smart DCR User Manual v2.0 (Vinzas Solutions India Pvt Ltd). It checks drawing format only (Pre-Check), not building rules. It is not affiliated with NKDA, and passing here does not guarantee the official Pre-Check will pass. The architect remains responsible for compliance with the rules.
