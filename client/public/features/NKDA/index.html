📋 Full Instructions

Step-by-step guide for the NKDA Smart DCR Pre-Check.

01

DXF Pre-Check

Upload one DXF file and review what the Smart DCR manual would reject

1

Save as ASCII DXF

In AutoCAD use SAVEAS and pick an ASCII DXF format. DWG files cannot be read in the browser.

2

Upload the DXF

Click or drag your .dxf file into the upload zone. Any filename is accepted.

3

Check Drawing

Click "⚡ Check Drawing". Only objects on FLOOR layers are checked; other layers are ignored, as in Smart DCR.

4

Review the Issues

Click an issue to zoom to the object. Red rings are errors, amber rings are warnings, and a grey cross marks an object with an error.

5

Download the Reports

Use Download PDF report for the full list, or Download marked-up DXF to see every problem on a new NONCOMPLIANT layer.

Important: This is an unofficial tool. It checks drawing format only, not building rules, and passing here does not guarantee the official Pre-Check will pass.
