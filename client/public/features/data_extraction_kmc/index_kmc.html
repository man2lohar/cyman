📋 Full Instructions

Step-by-step guide for EXTRACTED Excel Upload and DXF Layer Extractor.

01

Upload KMC Excel File

For extracting building area data via AutoCAD and Excel

1

Download the AutoCAD Script File

Click "Download .dxf file" on the Home screen to get the .dxe AutoCAD script that extracts layer data.

2

Run the Script in AutoCAD

Open your KMC drawing. Run the .dxe script via the SCRIPT command. AutoCAD extracts all layer data into an Excel file automatically.

3

Ensure All Sheets Are Present

The Excel file must contain all sheets — the MASTER sheet and the A sheet — saved together in one .xlsx or .xls file.

4

Upload the Excel File

Drag and drop your file into the upload zone, or click "Upload Excel File". Accepted: .xls, .xlsx, .csv.

5

Use the Menu Tabs

After upload the tab bar unlocks. Use Layer Tables → Filtered Tables → Floor Area → Parking → Occupancy → Final Summary in order.

6

Check for Errors

Use "Check Errors". Orange = duplicate data. Red = incorrect data that must be fixed in your drawing.

Tip: Always save all sheets together before uploading. Individual sheets cause calculation errors.
02

DXF Layer Extractor

For uploading DXF files to extract layers directly

1

Prepare Your DXF Files

You need exactly two DXF files: Master Sheet.dxf (any capitalisation) and A.dxf — must be exactly capital A.

2

Upload Master Sheet.dxf

Click or drag into the left drop zone. Case-insensitive — "master sheet.dxf", "Master Sheet.dxf" all accepted.

3

Upload A.dxf

Click or drag into the right drop zone. Filename must be exactly A.dxf — capital A only.

4

Extract Layers

Once both files are loaded, "⚡ Extract Layers" activates. Click it to parse both DXF files and extract all layer data.

5

Review Validation Warnings

If layers are in the wrong file a popup appears. Fix the files or click "Show anyway" to continue.

6

Results Feed the Same Tabs

Results load into the same data table as Excel uploads. All tabs work the same way.

Important: A.dxf must be exactly capital A. Files named a.dxf or Block A.dxf will be rejected.
