Feature Guide
  • Calendar: View all tasks by date.
  • Kanban: Drag-and-drop board — To Do → In Progress → Review → Done.
  • Assessment: KPIs, filters, sort, charts and full task table with time tracking.
  • Timeline: Milestones and tasks on a visual horizontal track per project.
  • Projects: Add projects with start/due dates and track per-project progress.
  • Team: Add members, assign tasks, view workload per person.
  • Reports: Burndown chart, velocity, workload, time summary, CSV export/import.
  • Settings: Accent colour, density, sort defaults, week start, overdue alerts.
